# Proposal Project1 — LaTeX Version

แปลงเอกสาร `Proposal Project1.docx` (เค้าโครงโครงงานคอมพิวเตอร์ ไดโน: เว็บแอปพลิเคชันศูนย์กลางของการท่องเที่ยวจังหวัดขอนแก่น
สาขาวิชาวิทยาการคอมพิวเตอร์ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น) ให้เป็นไฟล์ LaTeX ที่จัดฟอแมตตรงตามต้นฉบับ
และแยกเนื้อหาออกเป็นไฟล์ย่อยตามหัวข้อ เพื่อให้แก้ไข/เติมเนื้อหาภายหลังได้ง่าย

```

latex/
```

## วิธีคอมไพล์

ต้องใช้ **XeLaTeX** เท่านั้น (ไม่ใช่ pdflatex) เพราะต้องใช้ฟอนต์ไทยและการตัดคำภาษาไทยของ XeTeX:

```bash
cd latex
xelatex main.tex
```

รันซ้ำ 1 ครั้งถ้าเลขหน้า/การอ้างอิงยังไม่อัปเดต ผลลัพธ์จะได้ไฟล์ `latex/main.pdf`

หากต้องการดูเฉพาะบางหน้าโดยไม่เปิดโปรแกรมอ่าน PDF สามารถแปลงเป็นรูปได้ด้วย:

```bash
pdftoppm -png -r 150 -f <หน้าเริ่ม> -l <หน้าสิ้นสุด> main.pdf preview
```

## การแก้ไขเนื้อหา

- แก้ไขเนื้อหาแต่ละหัวข้อได้ที่ไฟล์ใน `latex/sections/` ตามชื่อหัวข้อ เช่น เติมตัวเลขงบประมาณที่
  `10-budget.tex` หรือแก้ไขบทที่ 4 ที่ `04-theory.tex`
- หมายเลขหัวข้อ (1., 4.1, 4.1.1 ฯลฯ) เกิดจาก `\section`/`\subsection`/`\subsubsection` ของ LaTeX เอง
  **ไม่ต้องพิมพ์เลขหัวข้อเองในเนื้อหา** ระบบจะเรียงเลขให้อัตโนมัติ
- รูปแบบการเยื้องหัวข้อ (แบบขั้นบันได ให้ 4.1 เยื้องเข้าไปจากตำแหน่งของ 4. และ 4.1.1 เยื้องเข้าไปจาก 4.1)
  และระยะห่างหลังเลขหัวข้อ (4 spaces สำหรับหัวข้อใหญ่ 1./2./3.../11., 2 spaces สำหรับหัวข้อย่อย) ถูกตั้งค่าไว้แล้วที่
  `main.tex` ไม่ต้องแก้ไขส่วนนี้เว้นแต่ต้องการเปลี่ยนรูปแบบจริง ๆ

## หมายเหตุ

- งบประมาณในหัวข้อ 10 ยังไม่มีตัวเลขกรอก เนื่องจากต้นฉบับ Word ก็ไม่มีเช่นกัน — ต้องกรอกเองภายหลัง
- ฟอนต์ TH Sarabun New แนบมาในโฟลเดอร์ `latex/fonts/` โดยตรง (อ้างอิงด้วย path สัมพัทธ์ใน `main.tex`)
  ทำให้คอมไพล์ได้แม้เครื่องที่ไม่ได้ติดตั้งฟอนต์นี้ไว้ในระบบ
